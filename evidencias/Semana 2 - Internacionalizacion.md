# Semana 2 - Internacionalización

Durante esta etapa del curso se incorporó la posibilidad de cambiar el idioma mostrado por la aplicación. El objetivo fue preparar TechShop para manejar textos mediante recursos de internacionalización en lugar de dejar todo el contenido escrito directamente en las vistas.

Contenido identificado en clase:
- Cambio de idioma desde la interfaz.
- Uso de textos parametrizados en Thymeleaf.
- Preparación de mensajes para distintos idiomas.

Esta evidencia documenta el contenido semanal descrito por el profesor para el avance de Proyecto Tienda.
