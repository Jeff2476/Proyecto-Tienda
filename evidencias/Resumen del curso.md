# Resumen del curso

Este archivo consolida el recorrido del Proyecto Tienda durante el curso de Desarrollo de Aplicaciones Web.

## Evolución principal

- Semana 2: internacionalización y cambio de idioma.
- Semana 3: inicio de base de datos y categorías.
- Semana 4: mantenimiento funcional de categorías.
- Semana 5: gestión de productos.
- Semana 6: tarjetas y filtros por categoría.
- Semana 8: consultas sobre productos.
- Semana 9: seguridad, login, logout y control por roles.
- Semana 10: usuarios almacenados en base de datos.
- Semana 11: registro y activación por correo.
- Semana 12: carrito, facturación y actualización de existencias.
- Semana 13: constantes y administración de roles.

Se utiliza una rama separada y un Pull Request como evidencia adicional del uso de herramientas de GitHub para organizar cambios antes de integrarlos a la rama principal.
