# Semana 10 - Usuarios en base de datos

En semana 10 se pasa de usuarios temporales a una gestión persistente utilizando la base de datos.

Contenido identificado en clase:
- Almacenamiento de usuarios en la base de datos.
- Listado y mantenimiento de usuarios.
- Consulta de información asociada a cada usuario.
- Continuidad del control de acceso mediante roles.
