# Semana 8 - Consultas

En esta etapa se incorporan consultas sobre la información almacenada en la tienda.

Ejemplo descrito en clase:
- Buscar productos dentro de un rango de precios.
- Mostrar únicamente los registros que cumplen la condición indicada.
- Uso de consultas derivadas para recuperar información desde la base de datos.

El profesor mostró como ejemplo la búsqueda de productos cuyo precio se encontrara entre dos valores determinados.
