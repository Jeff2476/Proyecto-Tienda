# Proyecto Tienda - TechShop

Repositorio del curso **Desarrollo de Aplicaciones Web**.

El proyecto corresponde a una tienda en línea desarrollada con Java, Spring Boot, Thymeleaf y MySQL. Durante el curso se trabajaron progresivamente internacionalización, categorías, productos, filtros, consultas, seguridad, usuarios, registro por correo, carrito de compras, facturación y administración de roles.

## Código fuente

El código Java real disponible está organizado en:

- `src/main/java/com/tienda/controller`
- `src/main/java/com/tienda/service`
- `src/main/java/com/tienda/repository`
- `src/main/java/com/tienda/domain`

Las vistas Thymeleaf disponibles están en `src/main/resources/templates`.

Los archivos cargados provienen del proyecto local y de los recursos de las lecciones 4, 11, 12 y 13 compartidos para esta entrega. Los ZIP recibidos no incluían las clases completas de dominio de semanas anteriores como `Categoria`, `Producto`, `Usuario` y `Rol`; por eso no se inventaron esas implementaciones.

## Evidencias

La carpeta `evidencias` conserva el resumen del contenido trabajado por semana. El historial de commits permite revisar tanto la documentación como la incorporación posterior del código fuente real.
