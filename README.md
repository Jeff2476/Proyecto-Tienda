# Proyecto Tienda - TechShop

Repositorio de evidencias del curso **Desarrollo de Aplicaciones Web**.

El proyecto corresponde a una tienda en línea desarrollada con Java, Spring Boot, Thymeleaf y MySQL. Durante el curso se incorporaron progresivamente internacionalización, categorías, productos, filtros, consultas, seguridad, usuarios, registro por correo, carrito de compras, facturación y administración de roles.

## Seguimiento del curso

Las evidencias están organizadas en la carpeta `evidencias` por semana. También se incluyen archivos representativos utilizados en las prácticas del curso.

## Tecnologías trabajadas

- Java 21
- Spring Boot
- Thymeleaf
- Spring Data JPA
- Spring Security
- MySQL
- Maven
- Bootstrap
