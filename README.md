# Proyecto Tienda - TechShop

Proyecto realizado para el curso **Desarrollo de Aplicaciones Web**.

TechShop es una tienda en línea desarrollada con Java, Spring Boot, Thymeleaf y MySQL.

## Contenido del proyecto

- Categorías y productos.
- Filtros y consultas.
- Inicio y cierre de sesión.
- Permisos por roles.
- Gestión y registro de usuarios.
- Envío de correos.
- Carrito de compras y facturación.
- Administración de roles y constantes.

## Estructura

El código Java se encuentra en `src/main/java/com/tienda`.

Las vistas y recursos del sitio están en `src/main/resources`.

El historial se puede revisar desde la pestaña **Commits** del repositorio y también está resumido en `evidencias/Historial de commits.md`.

## Tecnologías

Java 21, Spring Boot, Thymeleaf, Spring Data JPA, Spring Security, MySQL, Maven, Firebase Storage y Bootstrap.
